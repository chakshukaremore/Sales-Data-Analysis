# Sales Data Analysis Project

## Project Overview
This project analyzes Superstore sales data to understand sales performance, profitability, product performance, and regional trends.

## Tools and Technologies
- Python
- Pandas
- MySQL
- SQL
- Power BI

## Project Workflow
1. Cleaned the raw sales dataset using Python and Pandas.
2. Exported the cleaned data to a CSV file.
3. Imported 10,194 rows into a MySQL database.
4. Used SQL queries to analyze sales, profit, quantity, regions, categories, customer segments, products, and monthly trends.
5. Created an interactive-style sales dashboard in Power BI to visualize key metrics and trends.

## Key Metrics
- Total Sales: 2,326,534.49
- Total Profit: 292,296.18
- Total Quantity Sold: 38,654
- Total Records: 10,194

## SQL Analysis
The project includes queries for:
- Overall sales, profit, and quantity
- Region-wise performance
- Category-wise performance
- Top 10 products by sales
- Monthly sales and profit trends
- Customer segment analysis

## Power BI Dashboard
The dashboard includes KPI cards for Total Sales, Total Profit, and Total Quantity, along with visualizations for regional sales, category sales, sales trends, and top products.

## Project Structure
- `data/` — Raw dataset and cleaned CSV

- `sql/` — SQL analysis queries
